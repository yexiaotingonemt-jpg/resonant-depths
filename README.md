# 共鸣深井 · RESONANT

一款以「两人之间的连接」为核心的同屏合作动作肉鸽。两位守灯人穿过三章九境，收集可叠加遗物，击败三位守护者，为深井带回黎明。

[在线试玩](https://yexiaotingonemt-jpg.github.io/resonant-depths/) · [GitHub 源码](https://github.com/yexiaotingonemt-jpg/resonant-depths)

在线版本直接在桌面浏览器中游玩，无需安装。支持同一台电脑上的双人协作，也可使用 AI 搭档。推送到 `main` 后，GitHub Actions 会自动执行测试、构建并更新 GitHub Pages。

## 开始游玩

双击 `Start-Game.cmd`，浏览器会打开本地游戏。若初次打开时尚未连接，刷新一次即可。保留启动窗口，关闭窗口即可停止服务。

本机已安装 Node.js，发行包不需要安装 npm 依赖。服务仅监听 `127.0.0.1:5188`。

## 模式与操作

- **同屏双人**：同一键盘，或最多两只标准映射手柄。当前版本为本地合作。
- **独自启程**：P1 由你操作，P2 是会走位、施法、释放合击和救援的 AI。
- **标准 / 轻松**：轻松模式所受伤害降为 65%，其余流程相同。

| 操作 | P1 烬 · 逐火者 | P2 澜 · 引潮者 |
| --- | --- | --- |
| 移动 | WASD | 方向键 |
| 冲刺 | Space | Shift |
| 主动技能 | E：焰环爆燃 | Enter：范围伤害、治疗与短暂护盾 |
| 共鸣合击 | Q | / 或数字键盘 0 |

手柄：左摇杆移动，A 冲刺，X 技能，Y 共鸣。Esc / P 暂停。切换窗口自动暂停。部分键盘有多键冲突，建议键盘与手柄混用。

攻击自动瞄准最近的射程内敌人。魂链在两人相距 400 以内生效，可灼烧穿过的敌人并积累共鸣。共鸣满 100 后任意一人可释放全场伤害并清除敌方弹幕。倒地后，存活搭档靠近 78 距离内停留 2.8 秒即可救援；两人都倒地则结束。

## 远征与构筑

三章分别为苔光庭院、沉星回廊、无昼圣所。每第三境为守护者战；其余房间分多波敌潮。

清房后从随机三件遗物中选一件，强化对两人同时生效，可重复叠加。18 种遗物支持弹体穿透、多重射击、魂链强化、环绕星、减速、吸血、冲刺爆燃、救援和共鸣等构筑。中途可选择常规战场、星尘翻倍的精英试炼，或恢复生命的灵泉路线。

星尘用于本次远征与历史记录评分；不承担商店货币或永久强化功能。远征次数、通关数、最深房间及累计星尘保存在浏览器本地。结算可重试同一种子，复现随机波次及遗物序列。

## 开发

```powershell
npm.cmd install
npm.cmd run dev -- --port 5178
npm.cmd test
npm.cmd run build
node serve.mjs
```

Phaser + TypeScript + Vite。`src/sim.ts` 独立拥有规则状态，`scene.ts` 只负责呈现；`input.ts` 集中映射键盘和手柄，`audio.ts` 用 Web Audio 合成音效和环境音，`main.ts` 提供 DOM 菜单与 HUD。

18 项自动测试覆盖种子复现、暂停、救援和救援中断、团灭、魂链、冲刺、合击、遗物、首领弹幕、AI 救援意图、九房间状态流转，以及手柄和音频设备不可用时的降级。通过自动化的通关测试使用受控清敌来验证状态机，不代表真人平衡性测试。已在应用内浏览器实际检查双人移动、两种主动技能、暂停恢复、奖励选择和路线切换；手柄映射已实现，尚未用实体手柄验证。

另有 `node scripts/browser-devices.cjs` 的 Chromium 集成回归（运行前启动开发服务器 5178，安装 Chrome）：普通页面、真实 HTTP `Permissions-Policy: gamepad=()` iframe、音频 API 缺失和音频恢复被拒绝四种场景，均验证键盘位移、AI 更新、时间推进、暂停和恢复，无未捕获异常。音频 API 缺失和拒绝采用测试注入；手柄拒绝使用实际响应头，不模拟 API 返回。

美术由内置 Image Gen 生成，见 `ART.md`。无需 API key。音效由本地合成，无外部音频请求。
